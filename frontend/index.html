Why nano mesh

消息属于你，而不是平台。

从身份、传输到存储，整条链路都留在你自己的设备与节点上。没有中心消息服务器，也没有账号体系。

点对点直连

基于 iroh QUIC，节点之间直接传输。中心服务器不参与消息路由。

公钥即身份

节点 ID 由本地密钥生成；多设备证书、Grant 与吊销由签名链管理。

离线信箱

对端不在线时消息进入信箱，重新上线后自动同步，不丢消息。

多端同步

同一身份登录多台设备，联系人、群组、频道与消息保持一致。

群组与频道

私聊、群组、频道、presence、联系人册与内容寻址 blob 全部内置。

自建基础设施

可自建 relay 与 DNS（pkarr），也支持公共网络或纯局域网直连。

How it works

三步接入网格

身份、连接、存储三段都可自托管。你只需要一台设备，剩下的交给节点。

01

创建身份

首次启动在本地生成密钥，节点 ID 即公钥。不上传、不注册。

02

接入网格

通过 relay 打洞或中继，按公钥发现并连接对端。

03

收发与同步

在线直达；离线进信箱；多设备与联邦节点按主题同步。

nmspace 客户端→ iroh / QUIC→ nmd 节点→ redb 本地存储

FAQ

常见问题

关于身份、存储、平台与当前安全边界。

NANO MESH 是什么？
NANO MESH 是一套基于 iroh 的去中心化网格通信系统与桌面客户端，包含 P2P 私聊、群组、频道、离线信箱、多设备、去中心命名与联邦同步。
需要注册账号或中心服务器吗？
不需要注册。身份由本地密钥生成，节点 ID 就是公钥。默认接入公共网络；也可以自建 relay 与 DNS，完全脱离公共设施运行。
消息存在哪里？
客户端与节点使用本地 redb 持久化；离线消息暂存在节点信箱。消息不会上传到云端，也不需要中心数据库。
支持哪些平台？
当前发布 Windows 10+、macOS 12+ 与 Linux x64 桌面端。移动端 Tauri 客户端在仓库中持续开发，具体发布以 Gitee Releases 为准。
当前版本加密到什么程度？
连接身份基于公钥认证，多设备证书、Grant 与吊销已具备签名能力；消息内容的端到端加密尚未接入。当前版本请勿传输高敏感信息，安全设计见 安全说明。
可以自建节点吗？
可以。nmd 支持 selfhost / nat / lan 三种模式；自建 iroh-relay 与 iroh-dns-server 即可脱离公共网络。部署方式见仓库 docs。
从哪里获取最新版本？
Windows 安装包由门户直接下载；源码、设计文档与安全说明都在 Gitee 仓库中。
