状态:设计稿 → 待实施
关联代码:`clients/app/ui/js/composer.js`(选区遮罩 `openShotMask`)、
`clients/app/src-tauri/src/media.rs`(`capture_screen` / `shot_crop`)、`clients/app/ui/css/im.css`(`.shot-*`)。

## 1. 总体结构:三层画布

沿用现有遮罩,叠加:

```
.shot-mask    快照铺底(现状不变,事件层:拖选/移动选区)
.shot-sel     选区窗口(现状不变,透亮对齐)
canvas#shot-ink  标注层,绝对定位于选区内部,尺寸=选区尺寸
div#shot-text    内联文本框(仅输入文字时出现,输入完成栅格化到 ink 层)
.shot-bar    工具条(扩展为微信式两段:标注工具 + 操作按钮)
.shot-style  样式浮条(颜色/粗细/字号),点工具条上的小箭头弹出
```

DPI 处理:遮罩坐标系是 CSS 逻辑像素,快照是物理像素,沿用现状换算系数 `sx/sy`。**标注全部在 CSS 坐标系记录与渲染**,确认时统一乘 `sx/sy` 裁剪,文字/画笔在物理像素下重放,保证导出清晰。

## 2. 工具条(微信布局,含 QQ 独有项)

选区确认后(`placed=true`),工具条变为:

```
[▭矩形] [○椭圆] [➜箭头] [✏画笔] [🖍荧光] [🔢序号] [Aa文字] [▒马赛克] ▾  |  [↶撤销] [↺重做] | [✓完成] [✕] [💾] [📋复制] [📌钉图]
```

- 每个标注工具右侧带 `▾` 小箭头,弹出样式浮条。
- 马赛克无颜色,仅粗细。
- 序号工具(QQ):每点一次在点击处落一个带当前序号的圆标,序号自动 +1;样式只有颜色与半径。
- `✓完成`=走原 `confirm()`;`✕`=取消;`💾`=另存 PNG/JPEG;`📋`=复制 PNG 到剪贴板(替代发送,不进待发区);`📌钉图`=可选项,第二期。

图标沿用 `nmIcon()` 风格新增;文案进 `i18n.js`(`conv.shotRect` 等)。

## 3. 标注数据模型(纯前端,零后端改动为原则)

```js
// 一个标注 = 一条记录,可整体重绘 → 撤销/重做天然支持
{
  tool: "rect|ellipse|arrow|pen|marker|step|text|mosaic",
  color: "#ff4d4f",      // mosaic 时忽略
  size: 3,               // CSS px 线宽;文字=字号;mosaic=块半径
  // 几何(CSS 坐标,相对选区左上角):
  x0,y0,x1,y1,           // rect/ellipse/arrow 的起终点
  pts: [[x,y],...],      // pen/marker 的轨迹
  x,y,text,fontSize,     // text
  x,y,n                  // step
}
```

- `strokes[]` 数组 + `redo[]` 栈。撤销 = pop 到 redo;重做反之。
- 渲染:每次变更**全量重绘** ink canvas(选区通常 <2000px,全量重绘性能足够,避免增量管理的复杂度)。马赛克特殊处理见 §5。

## 4. 各工具交互(微信为准)

- **矩形/椭圆/箭头**:按下起笔、拖动、松手定形;拖动中实时预览。箭头三角形头部宽度∝线宽(约 3×)。
- **画笔**:pointermove 采样点;两点间以 `lineTo` + 圆头连接。
- **荧光笔**(QQ):同画笔,`globalAlpha≈0.45`,方头粗线(约 5×线宽),同色重复涂抹不叠加(用离屏 canvas 先画不透明、再以 alpha 一次性合成,微信/QQ 均如此)。
- **文字**:点击落点 → 就地出现透明背景输入框,字号=当前 size×4;Enter 确认 / Esc 取消;栅格化到 ink 层后允许框选不了(微信同款,文字一旦落定与其他笔画同级,只能撤销)。
- **序号**(QQ):点击落 ① 样式圆点(当前色实心圆+白字),序号全局计数,撤销时回退计数。
- **颜色/粗细**:样式浮条;颜色为微信同款 8 色行(红/黄/蓝/绿/紫/橙/黑/白)+ 3 档粗细(细/中/粗)。全局记忆,跨截图保留(localStorage)。

## 5. 马赛克(唯一需要快照数据的工具)

- 数据:记 `x0,y0,x1,y1` + 画笔轨迹(微信支持"涂抹式"打码,按轨迹推进)。
- 渲染:确认后从**原始快照**对轨迹覆盖区域逐块取像素均色(块大小=size×8),绘制到 ink 层。轨迹画到哪, mosaic 就推进到哪,已画区域不受后续选区移动影响。
- 原则:**马赛克作用在原图像素上,导出时不可逆**;ink 层与其余标注一起导出。

## 6. 选区本身的编辑(微信同款)

- 选区确认后,边缘 8 个把手 + 内部可拖动整体移动。
- 把手/移动与标注绘制冲突的约定:工具为 `select`(默认)时才可操作把手;点击任一标注工具后,鼠标在选区内即绘制。微信实际是"选区锁定后工具条第一项是矩形",我们同样:**一旦绘制第一个标注,选区即锁定**(不再允许调整大小),避免几何变化导致标注错位;撤销到 0 条标注时解锁。QQ 未锁定选区但实现复杂,不采用。
- 选区调整/移动仅影响 `rect()`;标注坐标相对选区原点,移动选区时整层 canvas 平移即可(重绘时统一加偏移)。

## 7. 确认导出

`confirm()` 改造:

1. 计算物理像素选区 `X=r.x*sx, Y=r.y*sy, CW=r.w*sx, CH=r.h*sy`。
2. 前端直接用离屏 canvas 合成(不再走后端 `shot_crop`,省一次 RGBA base64 往返):
   - 从快照 ImageData 取目标区域;
   - ink 层 canvas 以 `drawImage(inkCanvas, 偏移×sx/sy, 尺寸×sx/sy)` 叠加(注:ink 重放时按物理像素重画一遍,文字用 `fontSize×sx` 保证清晰);
   - `toBlob("image/jpeg", 0.85)`(微信默认 JPEG;含文字时可选 PNG,首期统一 JPEG)。
3. 无标注时退化为现状裁剪,纯前端完成;`shot_crop` 命令保留兜底(macOS 老路径)。
4. 出口:`pushPending(待发区)` / 复制剪贴板(`navigator.clipboard.write`,Windows webview 可用;失败则提示) / 保存文件(优先 Tauri dialog+fs 插件,若无则走 `<a download>`)。

## 8. 快捷键(对标微信)

- 拖选中:`Shift` = 正方形/正圆/水平垂直箭头;`Esc` = 取消。
- 选区确认后:`Ctrl+Z`/`Ctrl+Y` 撤销重做;`Enter` = 完成;`Esc` = 取消(有标注时先清空当前正在绘制的)。
- 全局:给后端注册系统级快捷键(如 `Alt+A`)列为可选二期,涉及 global-shortcut 插件与 Windows 注册表冲突排查,不在首期。

## 9. 后端改动(最小)

- **零必须改动**。可选优化:
  - `capture_screen` 增加返回 `png`(后端编码,替代前端 `pngOf` base64 双跳,省 ~1/3 内存);
  - 多显示器:首期仅主屏(现状),二期遍历 `Monitor::all()` 拼虚拟桌面大图。
- `shot_crop` 保留作 macOS 兼容兜底。

## 10. 实施拆分

1. **A 批(核心编辑器)**:三层画布重构 + strokes 数据模型 + 矩形/椭圆/箭头/画笔 + 颜色/粗细 + 撤销重做 + 尺寸提示。
2. **B 批**:文字、马赛克、序号、荧光笔。
3. **C 批**:选区移动/把手锁定策略 + 复制/保存/钉图 + 快捷键。
4. **D 批(可选)**:Alt+A 全局快捷键、多显示器、高斯模糊(QQ 式)、长截图。

移动端 `clients/mobile/` 不做(截图为桌面专属,现状一致)。
