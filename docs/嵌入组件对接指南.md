# TrueMate 嵌入组件对接指南

> 把 TrueMate **整个 agent 能力作为一个大模块**嵌入宿主应用（Web 页面 / Tauri 桌面应用 / 任何 WebView 容器）——侧栏、会话、专家、技能、连接器、设置全在模块内；悬浮球 + 面板只是可选形态，不是场景本体。
> 纯前端交付，无构建产物；组件契约与设计决策见 `documents/agent/plans/20261027_cmx-agent_智能体界面嵌入外部应用集成方案.md`。

## 一、三步接入

宿主页面只需要一个脚本标签和一个元素标签：

```html
<!-- 1. 引入组件入口（从本仓 ui/embed/truemate-app.js 取，自托管到宿主静态目录） -->
<script src="/your-static/truemate-app.js"></script>

<!-- 2. 放置组件（整面工作台） -->
<div style="height:100%">
  <truemate-app server="http://127.0.0.1:8099"></truemate-app>
</div>
```

或悬浮球 + 弹出面板（不占宿主布局）：

```html
<truemate-app server="http://127.0.0.1:8099" mode="panel"></truemate-app>
```

装配在运行期完成：组件从 `server`（或缺省的当前文档地址）拉取 TrueMate 的 `index.html` 解析出 css/js 清单并注入 shadow DOM——**宿主无需打包任何 TrueMate 资源，组件加载到的就是该服务正在运行的同一批文件，版本天然同源**。

## 二、运行环境与 `server` 属性（桥三态）

| 运行环境 | `server` 属性 | 连接方式 | 说明 |
| --- | --- | --- | --- |
| **Tauri 桥环境**（页面注入了 `window.__TAURI__`，且所在应用注册了 agent 内核命令） | 缺省或忽略 | **invoke 直连内核** | 无需服务地址；认证由宿主应用负责（§五）；css/js/vendor 由宿主随 ui/ 目录打进自家资产 |
| Web 壳 / 同源页面 | 缺省 | 同源相对请求 | 页面与 TrueMate Web 壳同源部署时开箱即用 |
| 纯浏览器 / WebView 宿主（无 Tauri API） | **必填** | 绝对基址请求 + `Authorization` 头 | 指向用户可达的 TrueMate 服务（本机 Web 壳 `http://127.0.0.1:8099`，或服务端部署 / 反代） |

基址规则统一为：**`server` 显式基址 > 当前文档地址**。跨源直连需要服务端允许宿主页源（CORS）或与宿主同源反代——**同机跨端口也算跨源**；同源部署（反代或页面由服务提供）则零配套。

## 三、扩展属性

| 属性 | 值 | 说明 |
| --- | --- | --- |
| `server` | URL | TrueMate 服务基址（按上表按环境缺省） |
| `token` | 字符串 | 门户令牌（持令牌宿主用；敏感页面建议运行期 `TrueMate.auth(token)` 传入，属性形态仅建议可信内网页面使用） |
| `user` | JSON 或用户名 | **用户信息直通（无令牌宿主的主形态）**：`user='{"user_id":"1001","username":"zhangsan","nickname":"张三"}'` 或 `user="zhangsan"`；组件经契约命令 `auth_user` 传服务端绑定会话（见 §五） |
| `mode` | `full` / `panel` | `full`=整面工作台（缺省）；`panel`=悬浮球 + 弹出面板 |
| `theme` | `light` / `dark` / `auto` | 亮暗主题；`auto` 跟随系统 `prefers-color-scheme` |
 | `settings-entrance` | `visible` / `hidden` | 组件内设置入口（活动栏头像钮）显隐；嵌入组件的活动栏默认整体隐藏（含此入口），设置经 `openSettings()` 打开——此属性保留为形态预留 |
| `setting-hide` | 分区键列表 | 隐藏设置中心分区（应用级页面）：逗号 / 空格分隔，如 `setting-hide="account,appearance,about,im"`。可用键：`account`(账户/用户信息) `models`(模型) `im`(IM遥控) `agents`(子智能体) `experts`(专家) `plugins`(插件) `skills`(技能) `mcp`(连接器) `commands`(命令) `hooks`(钩子) `memory`(记忆) `appearance`(外观/换肤) `about`(关于/版本更新)。被隐藏分区从导航移除，直索时自动重定向到首个可见分区。**应用级分区建议**：`account`（身份由宿主传入）/ `appearance`（换肤走宿主变量映射）/ `about`（版本属于独立应用）通常都应隐藏；`im`（IM 遥控）依赖服务面实现 `im_config` / `im_wechat_login` / `im_qq_login` 三条契约命令——宿主实现了即可保留（本仓 demo 即如此，面板可配可热重载），未实现建议隐藏 |
| `styles-url` | URL | 预留：宿主覆盖样式表地址（运行期拉取注入 shadow） |
| `z-index` | 数字 | 悬浮球 / 面板的层级（panel 态与宿主弹层竞争时用） |
| `hide-if-missing` | 布尔 | 服务不可达时静默隐藏（缺省呈占位态） |

属性运行期变更热响应（换 token / 主题 / 上下文），不重建组件。

> 嵌入态默认隐藏应用级**活动栏**（左侧图标条：视图切换 + 账户入口）——宿主持有应用导航，设置经 `openSettings()` 打开；会话列表侧栏保留（工作台头部可收合）。

## 四、JS API（window.TrueMate）

全局 API 绑定页面中第一个 `<truemate-app>`；多实例控制建议直接拿元素引用监听 DOM 事件。

| API | 说明 |
| --- | --- |
| `TrueMate.open()` / `close()` / `toggle()` | 面板打开 / 关闭 / 切换（panel 态；full 态无操作） |
| `TrueMate.openSettings(section?)` | 打开组件内设置页，可带分区直达（对接内置 `openSettings(sec)` 分区机制） |
| `TrueMate.closeSettings()` | 关闭设置页 |
| `TrueMate.send(text)` | 直发消息（纯文本直发，不携带任何参数拼接） |
 | `TrueMate.setTheme(v)` | `"light"` / `"dark"` / `"auto"` |
| `TrueMate.auth(token)` | 运行期传入 / 轮换令牌 |
| `TrueMate.authUser(u)` | 用户信息直通（对象或纯用户名串），经契约命令 `auth_user` 绑定会话 |
| `TrueMate.logout()` | 登出：清服务端会话，组件回占位态（宿主账号体系登出时同步调用） |
| `TrueMate.on(event, cb)` | 订阅事件（与 DOM 事件等价，二选一）；返回退订函数 |
| `TrueMate.destroy()` | 摘除组件（清理定时器 / 监听 / 订阅 / DOM） |

### DOM 事件（`addEventListener`，`composed: true` 向外冒泡）

| 事件 | detail | 说明 |
| --- | --- | --- |
| `ready` | `{protocol, mode}` | 装配完成 |
| `authenticated` | `{user}` | 认证通过 |
| `auth-error` | `{reason}` | `unauthorized`（令牌缺失 / 失效）或 `unreachable`（服务不可达）——组件呈现占位态，宿主可自行引导 |
| `session-changed` | `{session_id}` | 会话回合开始 |
| `turn-done` | `{session_id}` | 回合收尾 |
| `close` | — | 用户点面板收起钮（panel 态），宿主可据此收起容器 |

## 五、认证与用户信息

组件内没有登录页。认证三条通道，按宿主能力选一（组件解析顺序：`token` > `user` > 服务端既有会话探测）：

| 通道 | 宿主场景 | 传法 | 机制 |
| --- | --- | --- | --- |
| **用户信息直通（无令牌宿主的主形态）** | 集成方没有门户令牌，只有自己登录态的用户 | `user` 属性 / `TrueMate.authUser(u)`：JSON（`{"user_id":"1001","username":"zhangsan","nickname":"张三"}`）或纯用户名串 | 组件调契约命令 `auth_user`，服务端按传入用户信息绑定会话（内网可信断言模型） |
| **令牌直通** | 宿主持门户令牌 | `token` 属性 / `TrueMate.auth(token)` | `Authorization: Bearer` 头随请求 + 契约命令 `auth_token` |
| **服务端既有会话** | 本机 Web 壳已登录 / Tauri 桥宿主自管认证 | 无需传 | 组件以 `current_user` 探测，命中即用 |

- 通道全部失败 → 主区呈现「助手未连接」占位态（不出现任何账号密码输入），并发 `auth-error` 事件；服务端恢复后组件自动接入（内置看护轮询）。
- **Tauri 桥环境例外**：内核与宿主应用同进程，认证由宿主负责（组件以 `current_user` 探测）；`token` / `user` 通道不适用。
- **用户信息**：组件不维护任何用户资料，身份完全继承服务端会话；展示复用组件内既有位置（设置中心-账户分区）。会话 / 文件 / 记忆归属服务端该账号的数据根。
 
> 服务端配合点：现网 Web 壳的登录是账密命令（`cmd:"login"`）；`auth_user`（按传入用户信息绑定会话）与 `auth_token`（令牌校验 + `Authorization` 头）属服务端 / 部署侧配套契约，组件按契约先行，契约未具备时组件呈占位态，服务端已有会话时直接复用。**安全口径**：`auth_user` 是内网可信断言（宿主页面声明什么身份、服务端即采信），仅适用于可信内网部署；公网场景必须走令牌 / 账密并加校验。

## 六、换肤（宿主 → 组件）

1. **变量覆盖（主通道）**：CSS 自定义属性穿透 shadow 边界，宿主在元素上覆盖同名令牌即整站换色（`--primary` 为唯一种子，派生族自动联动）：

   ```css
   truemate-app {
     --primary: #2f6bff;
     --bg: #f7f8fa; --panel2: #ffffff;
     --ink: rgba(0,0,0,.88); --ink2: rgba(0,0,0,.62); --muted: rgba(0,0,0,.40);
     --border: rgba(0,0,0,.10);
   }
   ```

   公共令牌（背景两级 / 文字三阶 / 边框 / 主色族 / 语义色）受语义版本保护；其余令牌不承诺稳定。
2. **主题属性联动**：`theme` 属性 / `TrueMate.setTheme()`；宿主换肤 = 主题属性 + 品牌变量映射两步。
3. **受控通道**：`styles-url` 属性 / `::part()` 部件（预留）；不开放全量任意改写。

## 七、前置条件与已知边界

| 项 | 要求 / 边界 |
| --- | --- |
| 宿主 CSP | 装配执行依赖函数作用域包裹，宿主页面 CSP 需允许 `unsafe-eval`；宿主自身脚本请走外部文件 + 事件监听（`script-src 'self'` 下内联 `<script>` 与 onclick 属性会被拦截）；不满足时组件呈明确占位态（不白屏） |
| 协议 | 宿主页须以 http/https 提供（`file://` 的 fetch 限制不可用） |
| 跨源 | 跨源拉取 css/js 与 API 需服务端 CORS，或把 ui/ 静态目录同源自托管、`server` 只指向 API |
| 宿主容器尺寸 | `mode=full` 时宿主容器需给定高度（组件 `height:100%`）；宽度可任意——会话列的最小宽约束已在嵌入态解除，宽 markdown 表格在自身盒内横向滚动，不再溢出容器右缘 |
| 面板外点击 | 组件浮层监听位于 shadow 内——点击宿主页面区域不会收起组件内下拉（点击组件内部任意处 / Esc 可收起），属同文档嵌入的标准边界 |
| 多实例 | 同页多实例各持独立作用域与 UI 态（后端会话共享）；建议 1~2 个 |
| 宿主 localStorage | 同源嵌入时与宿主共用键空间；组件键已带 `cmx-*` / `truemate.*` 前缀 |
| vendor 预览库 | pdf/xlsx/pptx 预览渲染库按基址从服务端 `/vendor/*` 懒加载，服务不可达时预览降级不崩 |

## 八、本仓演示（桌面应用 · 真实内核）

```bash
cd demo/tauri-embed-demo
cargo run        # 打开桌面应用窗口（构建产物 target/debug/truemate-embed-demo.exe 可直接双击）
```

窗口即一个模拟的第三方业务系统「示例业务系统」（顶栏 + 单页），TrueMate 以**整面模块满贴嵌入**（无内边距直贴业务头部）。宿主页源码即 `ui/host.html` + `ui/host.js`（服务面经 `/demo/host.html` / `/demo/host.js` 路由吐出），第三方宿主可直接以此为模板：

- **整面模块**：`mode=full` 工作台——`user` 直通「张三」（`user_id` / `username` / `nickname`）、`setting-hide` 裁掉账户 / 外观 / 关于三个应用级分区；嵌入态默认隐藏应用级**活动栏**（左侧图标条：视图切换 + 账户入口）——宿主持有应用导航，设置经 `openSettings()` 打开；
- **IM 遥控分区可用**：`im_config` / `im_wechat_login` / `im_qq_login` 三条契约命令由 demo 服务面实现（桌面壳同名 Tauri 命令的命令总线版；UI 走 `im.js` 的 EMBED_CTX 分支）——配置可读写、保存即热重载、扫码凭证落盘即上线、通道桥真实运行。这是「嵌入态宿主可自带契约命令」的示范：面板之外的宿主定制能力，宿主侧按同一模式扩展即可；
- 顶栏按钮演示 `openSettings / setTheme`，状态灯由认证事件驱动；
- **CSP 收紧型宿主示范**：宿主页零内联脚本、零 onclick 属性，宿主逻辑全部在外部 `host.js`（`script-src 'self'` 放行；组件装配另需 `'unsafe-eval'`，见 §七）。

内核是**真实内核**：demo 以 path 依赖引入 `cmx-agent-app`，命令总线 / 流式回合 / 事件总线 / 附件直连真实内核（与 Web 壳、Tauri 壳同一个 `dispatch_json`）——真实模型对话、真实会话持久化，插件与连接器随数据根配置加载；鉴权面不配置（内核「本地单机模式」，登录门不强制），两条契约命令 `current_user` / `auth_user` 在 demo 服务面实现（用户信息写死「张三」），其余命令全部透传真实内核。数据根默认与 TrueMate 双壳同根（模型配置开箱复用，demo 发起的会话在 TrueMate 里可见）；设 `CMX_AGENT_DATA_DIR` 可隔离。指向其他服务用 `?server=<基址>`（同机跨端口也是跨源，需服务侧 CORS 或同源反代，见 §二 / §七）；开发自测可 `cargo run -- --server-only` 后在浏览器打开打印的地址（同一宿主页的网站形态，仅用于联调）。
